# 💳 Bank Management System in C++

An advanced **Bank Management System** built using **C++ Object Oriented Programming (OOP)** concepts.  
This project demonstrates the implementation of:

✨ Inheritance  
✨ Polymorphism  
✨ Virtual Functions  
✨ Dynamic Memory Allocation  
✨ Vector Container  
✨ Constructor & Destructor  
✨ Function Overriding  

---

# 📌 Project Overview

This project allows users to:

✅ Create Savings Account  
✅ Create Checking Account  
✅ Create Fixed Deposit Account  
✅ Deposit Money  
✅ Withdraw Money  
✅ Calculate Interest  
✅ Display All Accounts  

The system is fully menu-driven and works through the console.

# 🚀 Technologies Used

- C++
- OOP Concepts
- STL Vector

# 🧠 OOP Concepts Used

| Concept | Usage |
|--------|--------|
| Inheritance | Savings, Checking & FD account inherit BankAccount |
| Polymorphism | Virtual functions used |
| Encapsulation | Private data members |
| Abstraction | Common behavior in base class |
| Dynamic Binding | Runtime function overriding |

---

# 📂 Classes Used

## 🏦 BankAccount
Base class containing:
- Account Number
- Account Holder Name
- Balance
- Deposit & Withdraw Functions

---

## 💰 SavingsAccount
Derived class for:
- Interest Calculation

---

## 🏧 CheckingAccount
Derived class for:
- Overdraft Checking

---

## 📈 FixedDepositAccount
Derived class for:
- Fixed Deposit Interest Calculation
